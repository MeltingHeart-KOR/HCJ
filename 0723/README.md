# 👤 My Profile Page

> 프로필 사진과 SNS 링크를 한 페이지에 담은 **개인 소개 웹 페이지**입니다.
> 서버 없이 정적 파일(HTML + CSS)만으로 동작하며, GitHub Pages에 바로 배포할 수 있습니다.

---

## ✨ 주요 구성

| 영역 | 내용 |
|---|---|
| 프로필 사진 | 페이지 중앙에 사진 표시 (민트 톤 배경) |
| SNS 링크 | 이메일 · 메신저 · Facebook · 전화(Viber) 등 아이콘 버튼 |
| 소개 텍스트 | 이름 / 한 줄 소개 <!-- 실제 내용에 맞게 수정하세요 --> |

## 📁 파일 구성

```
profile-page/
├── index.html   # 페이지 구조
├── style.css    # 스타일 (배경, 프로필 카드, 아이콘)
├── README.md    # 이 문서
└── (사진 파일)  # 프로필 이미지 — index.html에서 참조하는 이름으로 저장
```

## 🚀 실행 방법

1. 폴더째 내려받은 뒤 `index.html`을 브라우저로 열면 끝
2. 별도의 서버(server.js)나 빌드 과정이 **필요 없습니다**

## 🌐 GitHub Pages 배포

1. 저장소에 폴더째 업로드
2. Settings → Pages 활성화
3. `https://<계정>.github.io/<저장소>/<폴더>/` 로 접속

> ⚠️ CSS·이미지 경로는 반드시 **상대 경로**(`./style.css`, `./photo.jpg`)여야
> 하위 경로에서도 깨지지 않습니다.

## 🛠️ 기술 스택

- **HTML5 + CSS3** (Vanilla, 프레임워크 없음)
- 외부 라이브러리 없음 → **오프라인에서도 동작**

## ✏️ 수정 포인트

- 프로필 사진 교체: 이미지 파일을 같은 이름으로 덮어쓰기
- SNS 링크 변경: `index.html`의 `<a href="...">` 주소 수정
- 색상 변경: `style.css` 상단의 배경/포인트 색상 값 수정
