# 🎯 name-cannon — 이름 뽑기 대포

여러 사람의 이름을 입력하면 각 이름이 **색색의 구슬**이 되어 대포에서 발사되고, 못(peg)·회전 풍차·깔때기를 통과해 떨어지는 물리 시뮬레이션 추첨기입니다. **가장 마지막에 떨어지는 구슬이 당첨** 🏆 됩니다.

> ✅ **완전 오프라인 동작** — 물리 엔진까지 직접 구현되어 외부 라이브러리·인터넷 연결이 전혀 필요 없습니다.

---

## 🚀 실행 방법

```bash
cd name-cannon
node server.js
```

- **npm 설치 불필요** — 의존성 제로 Node 정적 서버입니다.
- 브라우저에서 `http://localhost:3000` 접속.
- 📱 스마트폰: 같은 Wi-Fi에서 콘솔에 표시되는 **네트워크 주소**로 접속하면 됩니다.

---

## ✨ 주요 기능

| 기능 | 내용 |
|---|---|
| 명단 입력 | 한 줄에 한 명 (쉼표 구분도 OK) + 실시간 인원 카운트 + 🎲 샘플 8명 버튼 |
| 🚀 발사 | 대포가 **0.55초 간격**으로 구슬을 차례로 발사 (발사 순서는 셔플) |
| 장애물 | **못 7줄 지그재그** → **회전 풍차 2개**(서로 반대 방향) → **깔때기** |
| 당첨 규칙 | 먼저 떨어진 구슬은 ❌ 탈락 칩으로 쌓이고, **마지막에 떨어지는 구슬 = 🏆 당첨** |
| 연출 | 구슬마다 고유 색 + 이름표, 발사·탈락·당첨 파티클, 폭죽 + 진동 피드백 |
| ⏩ 배속 | 인원이 많을 때 ×3 빨리감기 원터치 |
| 중복 이름 | 같은 이름은 `(2)`, `(3)` 자동 구분 |

---

## 🧠 동작 원리

1. **물리 엔진 직접 구현** — 중력, 못 반발, **풍차 날개의 표면 속도를 반영한 충돌**(날개에 맞으면 튕겨 나감), 구슬끼리의 충돌까지 처리합니다.
2. **예측 불가능한 결과** — 못에 맞을 때 접선 방향 랜덤 지터를 넣어 매번 다른 경로가 나옵니다.
3. **끼임 방지 장치** — "마지막에 떨어지는 게 당첨" 규칙의 최대 리스크는 구슬이 구석에 끼는 것. **1.8초 이상 정지하면 자동으로 툭 쳐서** 굴려줍니다.
4. **고정 타임스텝(1/120초)** — 기기 성능과 무관하게 동일한 물리 품질을 보장합니다 (배속 모드에서도 물리 정확도 유지).

## ⚠️ 한계

- 결과는 물리 시뮬레이션 + 랜덤 지터로 결정되므로 **재현 불가능**합니다 (같은 명단이라도 매번 다른 결과 — 추첨기로서는 장점).
