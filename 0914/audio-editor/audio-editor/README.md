# 🎚️ audio-editor — 오디오 편집기

MP3·WAV 등 오디오 파일을 업로드해 **① 포맷 변환(WAV/MP3) ② 볼륨 조절 ③ 구간 Trim**을 할 수 있는 웹 앱입니다.

> 🔒 **모든 처리는 브라우저 안에서** 이루어집니다. 오디오 파일은 서버로 전송되지 않습니다.

---

## 🚀 실행 방법

```bash
cd audio-editor
node server.js
```

- **npm 설치 불필요** — 의존성 제로 Node 정적 서버입니다.
- 브라우저에서 `http://localhost:3000` 접속.
- 📱 스마트폰: 같은 Wi-Fi에서 콘솔에 표시되는 **네트워크 주소**로 접속하면 됩니다.

---

## ✨ 주요 기능

| 기능 | 내용 |
|---|---|
| 업로드 | 탭 선택 / 드래그&드롭 — MP3, WAV 등 (브라우저가 디코딩 가능한 포맷) |
| 파형 표시 | 업로드 즉시 파형 렌더링 + 길이·샘플레이트·채널 정보 표시 |
| ① 포맷 변환 | **WAV**(무손실 16bit PCM, 자체 인코더) / **MP3**(lamejs, 128·192·320kbps 선택) |
| ② 볼륨 조절 | 슬라이더 **0~200%** — 재생 중 실시간 반영, 파형 진폭도 함께 변화 |
| ③ 구간 Trim | 시작/끝 슬라이더로 구간 지정 → 파형 하이라이트 + **▶ 구간 재생** 미리듣기 |
| 편집 적용 | Trim+볼륨을 파형에 반영하고 이어서 추가 편집 가능 |
| 원본 복원 | ↩️ 언제든 원본 상태로 되돌리기 |
| 다운로드 | 파일명 지정 → 진행률 바와 함께 인코딩 후 ⬇️ 다운로드 |

## 🧠 동작 원리

1. **디코딩** — Web Audio API(`decodeAudioData`)로 브라우저가 직접 오디오를 PCM으로 변환합니다.
2. **비파괴 편집** — Trim·볼륨은 미리듣기 단계에서 원본을 건드리지 않고, "편집 적용" 또는 내보내기 시점에만 반영됩니다.
3. **WAV 인코딩** — RIFF 헤더 + 16bit PCM 인터리브를 자체 구현 (클리핑 처리 포함).
4. **MP3 인코딩** — lamejs(CDN)를 사용하되 **30ms 단위 청크 처리**로 화면이 얼지 않게 진행률을 표시합니다.
5. **메모리 관리** — 재변환 시 이전 Blob URL을 `revokeObjectURL`로 해제해 누수를 방지합니다.

## ⚠️ 한계

- **MP3 인코더(lamejs)는 CDN 로드** → 인터넷 연결이 필요합니다 (파일 자체는 전송 안 됨). CDN 실패 시 MP3 버튼이 자동 비활성화되고 WAV는 계속 사용 가능합니다.
- M4A/FLAC 등의 디코딩 가능 여부는 **브라우저에 따라 다릅니다** (MP3·WAV는 전 브라우저 OK).
- WAV 내보내기는 **16bit PCM** 기준입니다.
- 3채널 이상 오디오는 MP3 변환 시 스테레오로 자동 다운믹스됩니다.
