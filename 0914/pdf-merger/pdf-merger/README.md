# 📎 pdf-merger — PDF 병합기

여러 개의 PDF 파일을 업로드해 **하나의 PDF로 병합**하는 웹 앱입니다.

> ✅ **서버가 없습니다!** 순수 HTML + CSS + JS 3개 파일 — `index.html`을 더블클릭하면 바로 실행됩니다.
> 🔒 병합은 pdf-lib으로 **전부 브라우저 안에서** 처리되어, 파일이 어디로도 전송되지 않습니다.

---

## 🚀 실행 방법

```
pdf-merger 폴더의 index.html 을 브라우저로 열기 (더블클릭)
```

- **Node·npm·서버 전부 불필요** — 다른 프로젝트들과 달리 `server.js`가 없습니다.
- 📱 스마트폰에서도 폴더째 전달받아 index.html을 열면 사용 가능합니다.
- 단, **pdf-lib 라이브러리는 CDN 로드**이므로 인터넷 연결은 필요합니다 (파일 자체는 전송 안 됨).

---

## ✨ 주요 기능

| 기능 | 내용 |
|---|---|
| 다중 업로드 | 탭 선택 / 드래그&드롭, 여러 번 나눠 추가 가능 |
| 순서 조정 | ▲▼ 버튼으로 병합 순서 변경 (위→아래 순으로 합쳐짐), ✕ 개별 삭제 |
| 사전 분석 | 파일별 **페이지 수·용량** 표시 + 총 페이지/총 용량 합계 |
| 안전 장치 | PDF 아닌 파일 자동 제외 · 암호화/손상 PDF는 ⚠️ 표시 후 병합에서 제외 |
| 병합 | 진행률 바 + 현재 처리 중 파일명 표시, 완료 시 진동 피드백 |
| 다운로드 | 저장 파일명 직접 지정 (금지 문자 자동 치환) → ⬇️ 원터치 다운로드 |

---

## 🧠 동작 원리

1. 선택한 각 PDF를 브라우저 메모리에서 읽어 **pdf-lib**으로 페이지 수를 분석합니다 (이때 암호화/손상 파일을 미리 걸러냄).
2. 병합 버튼을 누르면 새 PDF 문서를 만들고, 목록 순서대로 각 파일의 전체 페이지를 복사해 넣습니다.
3. **파일마다 프레임 양보**(`setTimeout 0`)를 넣어 대용량 여러 개를 합쳐도 화면이 얼지 않습니다.
4. 결과는 Blob URL로 다운로드되며, 재병합 시 이전 URL을 `revokeObjectURL`로 해제해 메모리 누수를 방지합니다.
5. 파일이 2개 미만이면 병합 버튼이 비활성화되고, 버튼 텍스트가 "PDF를 2개 이상 추가하세요"로 바뀌어 안내를 겸합니다.

## ⚠️ 한계

- **인터넷 연결 필요** — pdf-lib을 CDN에서 로드합니다 (PDF 파일 자체는 전송되지 않음).
- **암호화된 PDF는 병합할 수 없습니다** (⚠️ 표시 후 자동 제외).
- 페이지 범위 지정 병합(예: 1번 파일의 2~5쪽만)은 미포함입니다 (확장 가능).
- 매우 큰 PDF 여러 개를 합칠 경우 브라우저 메모리 한도의 영향을 받을 수 있습니다.
