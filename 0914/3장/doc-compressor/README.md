# 📄 Smart Doc Compressor

문서·이미지 파일의 **용량을 줄여주는** 웹 앱입니다. PPTX, DOCX, PDF, 이미지 파일을 지원하며, 여러 파일을 동시에 올려 병렬로 압축할 수 있습니다.

> 🔒 **모든 파일은 브라우저 안에서만 처리되며, 서버로 전송되지 않습니다.**

---

## ✨ 주요 기능

| 형식 | 압축 방식 |
|---|---|
| **PPTX / DOCX** | 문서 내부의 이미지(media)를 축소·재인코딩 후 최고 압축률로 재포장 |
| **PDF** | 모든 페이지를 캡처 → 저화질 JPEG → 다시 PDF로 묶음 (저화질 스캔본 방식) |
| **이미지** (JPG/PNG 등) | 최대 1920px 리사이즈 + JPEG 재인코딩 |
| **HWP** | ❌ 미지원 — PDF나 Word로 변환 후 업로드하도록 안내 |

- **드래그 앤 드롭** 또는 버튼으로 업로드, 여러 파일 동시 처리
- 파일별 **프로그레스 바 + 실시간 상태 메시지** ("이미지 최적화 중… 3/12")
- 완료 시 **압축 전/후 용량과 절감률** 표시 (예: 2.4 MB → 800 KB, 67% 절감)
- 결과 파일명: `compressed_원본파일명`
- 압축 결과가 원본보다 커지면 **원본을 그대로 반환**하는 안전장치

## 🚀 사용 방법

1. 파일을 드롭존에 **드래그 앤 드롭**하거나 버튼으로 선택
2. 파일별 프로그레스 바로 진행 상황 확인
3. 완료되면 우측 **다운로드 버튼**이 활성화 → 클릭해 저장

## 🛠️ 기술 스택

- HTML / CSS / Vanilla JavaScript
- [JSZip](https://stuk.github.io/jszip/) — PPTX/DOCX 내부 접근 및 재포장 (CDN)
- [pdf.js](https://mozilla.github.io/pdf.js/) — PDF 렌더링 (CDN)
- [jsPDF](https://github.com/parallax/jsPDF) — PDF 재조립 (CDN)
- Canvas API — 이미지 리사이즈/재인코딩

## 📦 실행 & 배포

- **로컬**: `index.html`을 브라우저로 열면 끝 (서버 불필요)
- **GitHub Pages**: 폴더째 업로드하면 바로 동작 (상대 경로 사용)
- ⚠️ 라이브러리를 CDN에서 불러오므로 **인터넷 연결 필요**

## ⚠️ 알려진 한계

- **구형 바이너리 형식(.ppt / .doc)은 미지원** — .pptx / .docx로 다시 저장 후 업로드 안내
- PDF는 스캔본 방식이라 압축 후 **텍스트 복사·검색 불가** (대신 용량 절감 효과 큼)
- 이미지가 거의 없는 문서는 절감 효과가 작을 수 있습니다
