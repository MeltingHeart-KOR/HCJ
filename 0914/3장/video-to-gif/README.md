# 🎞️ Video to GIF

동영상 파일을 **GIF 애니메이션으로 변환**해주는 웹 앱입니다. 프레임을 캡처해 브라우저 안에서 GIF로 인코딩합니다.

> Make your own GIF Animation! 🎬
> 🔒 모든 변환은 브라우저 안에서만 처리되며, 영상이 서버로 전송되지 않습니다.

---

## ✨ 주요 기능

- **드래그 앤 드롭** 또는 버튼으로 동영상 업로드 (여러 개 가능 — 큐에 쌓여 순차 처리)
- **FPS 선택**: 5 / 10 / 15 / 24 / 29 (최대 29 FPS로 제한, 기본값 10)
- **출력 크기 선택**: 320 / 480 / 640px
- 파일 목록에 **첫 프레임 썸네일 + 프로그레스 바** — "프레임 캡처 중… 45/120" → "GIF 인코딩 중… 80%" 실시간 표시
- 완료 시 **변환 전/후 용량** 표시 후 다운로드 버튼 활성화
- 결과 파일명: `원본명.gif`

## 🚀 사용 방법

1. FPS와 출력 크기 선택
2. 동영상을 **드래그 앤 드롭**하거나 버튼으로 업로드
3. 프로그레스 바로 진행 확인 → 완료 후 **⬇ 다운로드**

## 🛠️ 기술 스택

- HTML / CSS / Vanilla JavaScript
- Video + Canvas API — 프레임 캡처
- [gif.js](https://jnordberg.github.io/gif.js/) — GIF 인코딩, Web Worker 기반 (CDN)

## 📦 실행 & 배포

- **로컬**: `index.html`을 브라우저로 열면 끝 (서버 불필요)
- **GitHub Pages**: 폴더째 업로드하면 바로 동작 (상대 경로 사용)
- ⚠️ 인코딩 라이브러리를 CDN에서 불러오므로 **인터넷 연결 필요**

## ⚠️ 알려진 한계

- **앞 30초까지만 변환** — 긴 영상 전체를 GIF화하면 파일이 지나치게 커져 브라우저가 멈출 수 있어 제한 (초과 시 토스트로 안내)
- FPS 상한 29 — GIF 특성상 FPS가 높을수록 용량이 급증하므로 기본값은 10
- 브라우저가 재생하지 못하는 코덱(일부 MOV/HEVC 등)은 변환 실패 — **MP4(H.264) 권장**
- 동영상 디코딩은 메모리를 많이 사용하므로 **한 번에 한 파일씩 순차 처리**
