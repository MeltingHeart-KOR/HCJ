# 🎬 Smart GIF Studio

브라우저에서 동작하는 **무료 GIF 편집기**입니다. 리사이즈, 크롭, 용량 줄이기, 포맷 변환, 회전, 최적화, 역재생, 속도 조절, 구간 자르기까지 — 총 9가지 편집 도구를 제공합니다.

> 🔒 **모든 처리는 사용자의 브라우저 안에서만 이루어집니다.**
> 파일이 외부 서버로 전송되지 않으므로 자료 유출 걱정 없이 사용할 수 있습니다.

---

## ✨ 주요 기능

| 도구 | 설명 |
|---|---|
| 📐 **Resize** | X/Y 슬라이더로 크기 조절 (현재값의 5%~300%). 🔒 자물쇠로 비율 고정/해제 |
| ✂️ **Crop** | 비율(1:1, 4:3, 3:4, 16:9, 9:16) 크롭 — 단색 여백 채움(Pad) 또는 확대(Zoom) 방식 선택 |
| 📉 **Downsizing** | 크기 축소 · 프레임 삭제 · 화질 낮추기 중 원하는 방법을 체크해 용량 감소 |
| 🔄 **Format Convert** | GIF → 영상(MP4/WebM) 또는 JPG(첫 프레임) 변환 |
| 🔃 **Rotate** | 90° / 180° / 270° 회전, 좌우/상하 뒤집기 |
| ⚡ **Optimize** | 팔레트 재인코딩으로 화질 손실 최소화하며 용량 정리 |
| ⏪ **Reverse** | 애니메이션 역재생 |
| 🐇 **Speed** | 재생 속도 0.25×~4× 조절 |
| 🎬 **Cut** | 시작/끝 프레임을 지정해 구간만 잘라 저장 |

- 편집 결과가 새 작업본이 되어 **연속 편집(체이닝)** 가능 (예: Resize → Crop → Speed)
- 파일 정보 표시: 용량, 해상도, Frame Rate, 총 프레임 수, 재생 시간
- 작업 중 실시간 프로그레스 바 표시
- 데스크톱(좌: GIF / 우: 패널), 모바일(상: GIF / 하: 패널) 반응형 레이아웃

## 🚀 사용 방법

1. 페이지를 열고 GIF 파일 1개를 **드래그 앤 드롭**하거나 **Choose File**로 선택
2. 오른쪽 **Editor Tools**에서 원하는 도구 클릭
3. 옵션 조절 후 **Go! 🚀** → 결과 GIF 확인
4. GIF 패널 우상단 **⬇ Download**로 저장
5. 새 파일로 시작하려면 **📂 Choose Another File** (모든 작업 초기화)

## 🛠️ 기술 스택

- HTML / CSS / Vanilla JavaScript (프레임워크 없음)
- [gifuct-js](https://github.com/matt-way/gifuct-js) — GIF 디코딩 (CDN)
- [gif.js](https://jnordberg.github.io/gif.js/) — GIF 인코딩, Web Worker 기반 (CDN)
- Canvas API — 프레임 변환 / MediaRecorder API — 영상 변환

## 📦 실행 & 배포

- **로컬**: `index.html`을 브라우저로 열면 끝 (서버 불필요)
- **GitHub Pages**: 폴더째 업로드 후 해당 경로로 접속 — 모든 경로가 상대 경로라 하위 디렉터리에서도 동작
- ⚠️ 디코더/인코더 라이브러리를 CDN에서 불러오므로 **인터넷 연결 필요**

## ⚠️ 알려진 한계

- MP4 변환은 브라우저 코덱 지원에 따라 다르며, 미지원 시 **WebM으로 자동 폴백**됩니다
- 투명 배경 GIF는 재인코딩 시 투명도가 일부 소실될 수 있습니다
- 대용량(수십 MB) GIF는 처리에 시간이 걸릴 수 있습니다
