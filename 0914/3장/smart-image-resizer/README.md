# 🖼️ Smart Image Resizer

사진의 **캔버스 비율을 바꿔주는** 웹 앱입니다. 원하는 비율을 고르고 Padding(여백 채움) 또는 Crop(잘라내기) 방식으로 여러 장을 한 번에 변환할 수 있습니다.

> 🔒 **모든 변환은 브라우저 안에서만 처리되며, 사진이 서버로 전송되지 않습니다.**

---

## ✨ 주요 기능

- **비율 선택**: 1:1 / 3:4 / 4:3 / 9:16 / 16:9 + ✏️ 커스텀 직접 입력
- **변환 방식 2종**
  - 🖼️ **Padding** — 사진 전체를 보존하고 남는 공간을 여백으로 채움 (여백 색상 선택 가능: 컬러 피커 + 프리셋 4종, 기본 흰색)
  - ✂️ **Crop** — 중앙 기준으로 잘라내 캔버스를 꽉 채움
- **여러 장 동시 업로드** — 드래그 앤 드롭 또는 버튼
- 파일별 **썸네일 + 프로그레스 바**, 완료 시 개별 다운로드 활성화
- 모든 작업 완료 시 **📦 일괄 다운로드(zip)** 활성화
- 결과 파일명: `resized_원본명.jpg` (투명 PNG는 `.png` 유지)
- 압축 전/후 용량 표시

## 🚀 사용 방법

1. 사진(여러 장 가능)을 **드래그 앤 드롭**하거나 버튼으로 선택
2. **비율** 선택 (또는 커스텀 입력)
3. **Padding / Crop** 방식 선택 — Padding이면 여백 색상도 지정
4. 🚀 변환 시작 → 파일별 프로그레스 확인
5. 개별 ⬇ 다운로드 또는 전체 완료 후 **📦 일괄 다운로드(zip)**

## 🛠️ 기술 스택

- HTML / CSS / Vanilla JavaScript
- Canvas API — 리사이즈 / 패딩 / 크롭
- [JSZip](https://stuk.github.io/jszip/) — 일괄 다운로드용 zip 생성 (CDN)

## 📦 실행 & 배포

- **로컬**: `index.html`을 브라우저로 열면 끝 (서버 불필요)
- **GitHub Pages**: 폴더째 업로드하면 바로 동작 (상대 경로 사용)
- ⚠️ **일괄 다운로드(zip) 기능만 인터넷 필요** (JSZip CDN) — 나머지 변환 기능은 오프라인에서도 동작

## ⚠️ 알려진 한계

- 출력 해상도는 긴 변 **최대 2400px**로 제한 (브라우저 성능 보호)
- 같은 파일명이 여러 개면 zip 저장 시 자동으로 `_1`, `_2`가 붙습니다
