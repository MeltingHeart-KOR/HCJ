# 🚪 away-screen — 자리 비움 안내 화면

잠시 자리를 비울 때 **일정 · 돌아오는 시간 · 안내 문구**를 입력하면, 살아 움직이는 그라데이션 위에 **실시간 카운트다운**과 함께 전체 화면으로 표시해 주는 웹 앱입니다.

> ✅ **완전 오프라인 동작** — 외부 라이브러리·인터넷 연결이 전혀 필요 없습니다.

---

## 🚀 실행 방법

```bash
cd away-screen
node server.js
```

- **npm 설치 불필요** — 의존성 제로 Node 정적 서버입니다.
- 브라우저에서 `http://localhost:3000` 접속.
- 📱 스마트폰: 같은 Wi-Fi에서 콘솔에 표시되는 **네트워크 주소**로 접속하면 됩니다.

---

## ✨ 주요 기능

| 기능 | 내용 |
|---|---|
| 일정 입력 | 프리셋 칩(회의 중/점심 식사/외근/휴식…) 또는 직접 입력 |
| 복귀 시간 | 시각 지정 + **+10분/+30분/+1시간/+2시간** 원터치 버튼 |
| 안내 문구 | 선택 입력 (예: "급한 용무는 내선 1234로") |
| 안내 화면 | **일정이 최대 크기 글자**(최대 7.5rem) + 복귀 시각 + 실시간 카운트다운 + 문구 배지 |
| 그라데이션 | 6색 그라데이션(18초 주기) + 블러 빛 덩어리 3개의 2중 레이어 "오로라" 애니메이션 |
| 카운트다운 | 초 단위 실시간, **5분 이하 맥동 강조**, 0 도달 시 **"곧 돌아옵니다!"** 전환 |
| 화면 유지 | **Wake Lock**으로 표시 중 화면 절전 방지 (탭 복귀 시 자동 재획득) |

---

## 🧠 동작 원리

1. 필수값(일정·복귀 시간)이 채워지면 확인 버튼이 활성화됩니다.
2. 확인 시 **자동 전체 화면** 진입 + 안내 화면으로 전환됩니다.
3. 이미 지난 시각을 입력하면 **내일로 자동 해석**하고 "(내일)"로 표기합니다.
4. 숫자는 `tabular-nums`로 폭을 고정해 초가 바뀌어도 글자가 떨리지 않습니다.
5. 종료는 실수 방지를 위해 **두 번 탭/더블클릭**입니다 (하단 힌트가 잠시 표시 후 흐려짐).

## ⚠️ 한계

- **Wake Lock API**는 일부 구형 브라우저에서 지원되지 않을 수 있습니다 (미지원 시에도 나머지 기능은 정상 동작).
- 전체 화면 자동 진입은 브라우저 정책상 사용자 클릭(확인 버튼)에 의해서만 동작합니다.
- 알림음·테마 색 선택 기능은 포함되어 있지 않습니다 (확장 가능).
