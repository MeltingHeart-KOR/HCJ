# 📝 textrank-app — TextRank 문서 요약기

PDF/DOCX 문서를 업로드하면 **TextRank 알고리즘**으로 핵심 문장만 추출해 요약해 주는 웹 앱입니다. **슬라이더로 요약 분량을 1~5문장** 사이에서 실시간 조절할 수 있습니다.

> 🔒 **파일은 서버로 전송되지 않습니다.** 텍스트 추출(pdf.js + JSZip)과 TextRank 계산이 전부 브라우저 안에서 처리됩니다.

---

## 🚀 실행 방법

```bash
cd textrank-app
node server.js        # npm install 불필요! (의존성 제로)
# → http://localhost:3000
```

- Node.js만 설치되어 있으면 됩니다 (외부 패키지 없음).
- ※ pdf.js / JSZip은 CDN으로 로드되므로 **브라우저에 인터넷 연결이 필요**합니다. (문서 파일 자체는 어디로도 전송되지 않습니다)

---

## ✨ 주요 기능

| 기능 | 내용 |
|---|---|
| 문서 업로드 | PDF · DOCX, 탭 선택 + 드래그&드롭, 페이지별 진행률 표시 |
| **TextRank 요약** | 외부 라이브러리 없이 직접 구현 (문장 유사도 그래프 + PageRank) |
| **분량 슬라이더** | 최소 1문장 ~ 최대 5문장, 움직이는 즉시 실시간 반영 |
| 중요도 표시 | 각 문장에 **순위 배지**(1위는 금색 글로우) + **중요도 % 바** |
| 부가 기능 | 압축률 통계 · 📋 요약 복사 · 원문 미리보기(접이식) |

## 🧠 TextRank 동작 원리 (원 논문 방식)

1. **문장 분리** — 종결부호 + 문단 경계 기준, 10자 미만 조각(머리글 번호 등) 자동 제외
2. **토큰화** — 한국어 **조사 자동 제거**(`알고리즘은`/`알고리즘이` → 동일 단어로 인식) + 한/영 불용어 필터
3. **유사도 그래프** — 유사도 = 공통 단어 수 ÷ (log|S₁| + log|S₂|)
4. **PageRank 반복** — damping 0.85, 수렴 시 조기 종료
5. **출력** — 점수 상위 k개 문장을 **원문 순서대로** 표시

### 설계 포인트

- **채점은 파일당 1회, 슬라이더는 캐시 사용** — TextRank 계산은 한 번만 수행하고, 슬라이더는 캐시된 점수에서 상위 k개만 다시 뽑기 때문에 **지연 0으로** 반응합니다.
- 문장이 5개 미만인 짧은 문서는 **슬라이더 최대값이 자동 보정**됩니다.
- 한국어 조사 제거가 없으면 같은 단어가 전부 다른 단어로 취급되어 요약 품질이 크게 떨어지기 때문에, 토큰화 단계에 조사 스트리핑을 내장했습니다.

## ⚠️ 알아두실 한계

- **스캔본 PDF**(이미지로만 된 문서)는 추출할 텍스트가 없어 요약이 불가하며, 안내 문구가 표시됩니다. (OCR 미지원)
- **암호가 걸린 PDF**는 분석할 수 없으며 에러 안내가 표시됩니다.
- TextRank는 **추출 요약**(원문 문장을 그대로 뽑는 방식)입니다. 문장을 새로 써주는 생성 요약과는 다릅니다.
