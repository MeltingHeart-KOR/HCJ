# 📄 doc-counter — PDF·DOCX 문서 분석기

PDF/DOCX 문서를 업로드하면 **글자 수 · 단어 수 · 공백 개수 · 이미지 개수**를 분석해 주는 웹 앱입니다.

> 🔒 **파일은 서버로 전송되지 않습니다.** 모든 분석(pdf.js + JSZip)이 브라우저 안에서 처리되므로 민감한 문서도 안심하고 사용할 수 있습니다.

---

## 🚀 실행 방법

```bash
cd doc-counter
node server.js        # npm install 불필요! (의존성 제로)
# → http://localhost:3000
```

- Node.js만 설치되어 있으면 됩니다 (외부 패키지 없음).
- 스마트폰에서 사용하려면 같은 Wi-Fi에서 콘솔에 표시되는 네트워크 주소로 접속하세요.
- ※ pdf.js / JSZip은 CDN으로 로드되므로 **브라우저에 인터넷 연결이 필요**합니다. (문서 파일 자체는 어디로도 전송되지 않습니다)

## ✨ 주요 기능

### 분석 항목

| 핵심 4대 지표 | 세부 지표 |
|---|---|
| **글자 수** (공백 포함) | 글자 수 (공백 제외) |
| **단어 수** | 한글 글자 수 |
| **공백 개수** (스페이스 · 탭 · 전각공백) | 줄 수 |
| **이미지 개수** | 페이지 수 (PDF) |

### 사용 방법

1. 파일 영역을 **탭해서 선택**하거나 **드래그&드롭**으로 PDF/DOCX 업로드
2. 다중 페이지 문서는 **진행률 바**로 분석 상황 표시
3. 결과 카드에 **카운트업 애니메이션**과 함께 통계 표시
4. 하단에서 **추출 텍스트 미리보기**(앞 1,000자) 확인 가능

---

## 🧠 동작 원리

| 형식 | 텍스트 추출 | 이미지 카운트 |
|---|---|---|
| **PDF** | pdf.js로 페이지별 텍스트 콘텐츠 추출 | 페이지 렌더링 연산자를 스캔해 실제로 그려지는 이미지를 카운트 (같은 페이지 내 중복 객체는 1회만) |
| **DOCX** | JSZip으로 압축 해제 후 **XML 파서**로 `w:t` / `w:tab` / `w:br` / 문단을 정확히 추출 | 본문의 `w:drawing` / `w:pict` 요소 기준, 없으면 `word/media` 폴더로 폴백 |

## 📁 파일 구성

```
doc-counter/
├── server.js     # 의존성 제로 정적 서버 (Node 내장 모듈만 사용)
├── index.html    # 앱 화면
├── style.css     # 모바일 우선 스타일 (48px+ 터치 타깃, safe-area 대응)
└── app.js        # 분석 로직 (pdf.js + JSZip, 전부 브라우저 내 처리)
```

---

## ⚠️ 알아두실 한계

- **스캔본 PDF**(이미지로만 된 문서)는 텍스트가 0자로 나옵니다 — 미리보기에 안내 문구가 표시됩니다. (OCR 미지원)
- **암호가 걸린 PDF**는 분석할 수 없으며 에러 안내가 표시됩니다.
- DOC(구형 워드), HWP 형식은 지원하지 않습니다.

## 🛠 기술 스택

- **서버**: Node.js 내장 모듈만 사용한 정적 파일 서버 (외부 의존성 0)
- **클라이언트**: 순수 HTML/CSS/JS + pdf.js(CDN) + JSZip(CDN)
- **디자인**: 모바일 우선, 드래그&드롭 + 탭 선택 모두 지원
