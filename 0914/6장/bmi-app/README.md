# ⚖️ bmi-app — BMI & 표준체중 계산기

키 · 몸무게 · 성별을 입력하면 **BMI 지수**를 계산하고, **표준체중 대비 90% / 100% / 110%** 기준까지 **몇 kg을 빼거나 찌워야 하는지** 보여주는 웹 앱입니다.

---

## 🚀 실행 방법

```bash
cd bmi-app
node server.js        # npm install 불필요! (의존성 제로)
# → http://localhost:3000
```

- Node.js만 설치되어 있으면 됩니다 (외부 패키지 없음, CDN도 사용하지 않아 **완전 오프라인 동작**).
- 스마트폰에서 사용하려면 같은 Wi-Fi에서 콘솔에 표시되는 네트워크 주소로 접속하세요.

## ✨ 주요 기능

### 화면 구성

| 영역 | 내용 |
|---|---|
| 입력 | 성별 칩(👨/👩) + 키(cm) + 몸무게(kg) → 모두 채우면 계산 버튼 활성화 |
| BMI 결과 | **초대형 BMI 숫자 카운트업** + 분류 배지 + **5색 게이지 바**에 ▼ 마커가 내 위치로 이동 |
| 🎯 목표 카드 | **90% / 100% / 110%** 카드 3장 — 목표 체중과 **몇 kg 감량▼/증량▲** 필요한지 색깔 배지로 표시 |

### 색상 규칙

- 감량 필요 → 🔴 빨강 배지 (▼ n.n kg)
- 증량 필요 → 🔵 파랑 배지 (▲ n.n kg)
- 이미 범위 안 → 🟢 **✅ 달성!** 배지

---

## 🧮 계산 방식

| 항목 | 공식 |
|---|---|
| **BMI** | 몸무게(kg) ÷ 키(m)² |
| **표준체중** | 키(m)² × **22 (남성)** / **21 (여성)** ← 성별을 입력받는 이유 |
| **목표 체중** | 표준체중 × 0.9 / 1.0 / 1.1 |
| **필요 증감량** | 목표 체중 − 현재 체중 (소수 첫째 자리) |

### BMI 분류 (대한비만학회 기준)

| 분류 | BMI 범위 |
|---|---|
| 저체중 | < 18.5 |
| 정상 | 18.5 ~ 24.9 |
| 과체중 | 25 ~ 29.9 |
| 비만 | 30 ~ 34.9 |
| 고도비만 | ≥ 35 |

### 계산 예시

- 남성 170cm · 80kg → BMI 27.7, 표준체중 63.6kg
  - 90%(57.2kg)까지 **▼ 22.8kg 감량**
  - 100%(63.6kg)까지 **▼ 16.4kg 감량**
  - 110%(69.9kg)까지 **▼ 10.1kg 감량**
- 여성 160cm · 45kg → 100% 기준 **▲ 8.8kg 증량**
