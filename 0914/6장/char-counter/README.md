# ✏️ 글자수 세기 — 한글 2byte 계산기

텍스트를 입력하면 실시간으로 글자 수와 byte 수를 계산해주는 모바일 우선 웹사이트.

## 핵심 규칙 (EUC-KR 방식)

| 문자 종류 | byte |
|---|---|
| 한글 (완성형·자모), 한자, 일본어, 전각 기호 | **2byte** |
| 영문, 숫자, 반각 기호, 공백, 줄바꿈 | **1byte** |

기업 입사지원서·자기소개서, SMS 단문 등에서 널리 쓰이는 계산 방식.

## 기능

- **실시간 카운트**: 글자(공백 포함/제외), byte(공백 포함/제외), 한글 글자, 단어, 줄, 공백
- **제한 게이지**: SMS 90byte / 자소서 2,000byte / 이력서 4,000byte — 90% 초과 시 주황, 초과 시 빨강 경고
- **도구 버튼**: 붙여넣기 / 복사 / 지우기 (토스트 알림)
- **모바일 최적화**: 핵심 지표 상단 고정(sticky), 48px+ 터치 타깃, iOS 입력 확대 방지, safe-area 대응

## 기술 스택

- **Node.js** 내장 모듈만 사용한 의존성 제로 정적 서버 (`npm install` 불필요)
- Vanilla JS + CSS (프레임워크 없음)

## 실행

```bash
node server.js
# → http://localhost:3000
```

스마트폰: 같은 Wi-Fi에서 `http://<PC IP>:3000`
