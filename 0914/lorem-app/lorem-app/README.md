# ✒️ lorem-app — Lorem Ipsum 생성기

슬라이더로 분량을 조절하는 Lorem Ipsum 더미 텍스트 생성기입니다. 기본 **150자**로 시작하고, **최소 10자 ~ 최대 5,000자** 범위에서 **정확히 요청한 글자 수**로 텍스트를 만들어 줍니다.

> ✅ **완전 오프라인 동작** — 외부 라이브러리·인터넷 연결이 전혀 필요 없습니다.

---

## 🚀 실행 방법

```bash
cd lorem-app
node server.js
```

- **npm 설치 불필요** — 의존성 제로 Node 정적 서버입니다.
- 브라우저에서 `http://localhost:3000` 접속.
- 📱 스마트폰: 같은 Wi-Fi에서 콘솔에 표시되는 **네트워크 주소**로 접속하면 됩니다.

---

## ✨ 주요 기능

| 기능 | 내용 |
|---|---|
| 분량 슬라이더 | **10 ~ 5,000자**, 움직이는 즉시 실시간 반영 (기본값 150자) |
| 정확한 글자 수 | 요청한 글자 수와 출력 글자 수가 **1자도 어긋나지 않음** |
| 프리셋 버튼 | 50 / 150 / 500 / 1,000 / 3,000 / 5,000 원터치 |
| 통계 | 글자 수 대형 표시 + 단어 수 칩 (변경 시 bump 애니메이션) |
| 🎲 새로 생성 | 다른 랜덤 텍스트로 재생성 |
| 📋 복사 | 클립보드 복사 + 토스트 알림 (구형 브라우저 폴백 포함) |

## 🧠 동작 원리

1. **마스터 텍스트 방식** — 5,000자짜리 텍스트를 한 번 생성해 두고, 슬라이더는 **앞부분을 잘라** 보여줍니다. 분량을 늘리면 뒤에 이어지고 줄이면 뒤가 잘릴 뿐, 앞 내용은 그대로 유지되어 UX가 안정적입니다.
2. **자연스러운 문장 구조** — 관용 도입부(`Lorem ipsum dolor sit amet...`) + 8~18단어 문장 + 쉼표 + 문단 나누기로 실제 인쇄용 더미 텍스트 형태를 만듭니다.
3. **마무리 다듬기** — 정확히 n자로 자를 때 마지막 글자가 공백·쉼표면 마침표로 치환합니다 (글자 수는 유지).
4. 슬라이더는 터치 영역 확대 + `touch-action: pan-x`로 모바일 세로 스크롤과 충돌하지 않습니다.
