# 🔮 오늘의 운세 — 다섯 원소 점술소

이름·생일·성별을 입력하고 불🔥/물💧/나무🌳/땅⛰️/바람🌬️ 중 하나를 고르면
오늘의 운세를 알려주는 모바일 우선 웹사이트.

## 실행
```bash
node server.js        # npm install 불필요 (의존성 제로)
# → http://localhost:3000
```

## 구조
```
fortune-site/
├── server.js          # Node.js 내장 모듈만 사용한 정적 서버
├── public/
│   └── index.html     # SPA (히어로 → 입력 → 원소 선택 → 결과)
└── README.md
```

## 특징
- 별빛 파티클 배경 + 수정구 히어로 애니메이션
- 시드 기반 난수: 같은 사람 + 같은 원소 + 같은 날짜 = 같은 운세 (자정에 갱신)
- 운세 지수 링 게이지 카운트업, 애정/금전/건강/일 별점, 행운의 색·숫자·아이템, 원소별 조언
- 모바일 최적화: 48px+ 터치 타깃, safe-area 대응, iOS 확대 방지(16px 입력)
