## 🛠️ 9/14 ~ 9/15 — 실습: 프롬프트 입력 & 바이브 코딩

### 1️⃣ 교재 실습

- 교재 **3장, 6장**에 있는 프롬프트를 직접 입력하며 실습합니다.
- 프롬프트 → 결과 확인 → 수정 반복(바이브 코딩)으로 결과물을 완성합니다.

### 2️⃣ GitHub 업로드

- 완성한 결과물을 **본인 GitHub 저장소에 업로드**합니다.
- 저장소에는 반드시 **README.md**를 포함하고 편집합니다.

### 3️⃣ README.md 작성 실습 — 3단계 프롬프트 흐름

md 파일을 "구하고 → 편집하고 → 활용"하는 순서로 진행합니다.

| 단계 | 하는 일 | 사용할 프롬프트 (예시) |
|------|---------|------------------------|
| ① md 파일 구하기 | AI에게 필요한 md 파일 목록과 초안을 요청 | 💬 *"나는 이런 사이트를 만들려고 하는데, 필요한 md 파일은 어떤 것이 있을까?"* |
| ② md 파일 편집 | 받은 md 파일을 내 프로젝트에 맞게 직접 수정 | (내 사이트의 목적 · 기능 · 화면 구성에 맞게 내용 편집) |
| ③ 사이트 제작 | 편집한 md 파일을 기준으로 사이트 생성 요청 | 💬 *"이런 md 파일을 참조하여 사이트를 만들어줘"* |

> 💡 **포인트** — md 파일(기획 문서)을 먼저 다듬은 뒤 코딩을 요청하면, AI가 만드는 결과물의 방향이 훨씬 정확해집니다.
